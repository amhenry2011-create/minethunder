# MineThunder (Minecraft 1.21.1 · NeoForge)

**MineThunder** 是一款面向 Minecraft 1.21.1 (NeoForge) 的硬核现代空战与拟真固定翼飞行模组。
模组集成了**移植自 Simple Planes（简单飞机）并深度重构为微软模拟飞行（MSFS）级硬核气动/冷舱启动流程的固定翼飞机系统**，以及全套**现代脉冲多普勒雷达（SRC PD / TWS / ACM / STT / GMI / SEA）、超视距数据链（BVR）、雷达告警接收机（RWR）、空空导弹（ARH / SARH / IR）与干扰弹（箔条/热焰弹）系统**。

### 2. 航空发动机与燃料补充
每架新放置的飞机默认内置一台**熔炉活塞发动机**并带有初始试飞燃料。
* **更换/升级发动机**：手空或持发动机**潜行（Shift）+ 右键飞机**之外，直接手持下列发动机物品**右键飞机**即可换装（原发动机自动退回背包）：
  1. **熔炉活塞航空发动机 (`minethunder:furnace_engine`)**：推力倍率 `1.0x`，无加力燃烧室。支持煤炭、木炭、煤炭块、烈焰棒右键加油。
  2. **液冷航空增压发动机 (`minethunder:liquid_engine`)**：推力倍率 `1.35x`，无加力燃烧室。高空性能更佳，支持熔岩桶、烈焰粉、煤炭块右键加油。
  3. **加力涡轮喷气发动机 (`minethunder:jet_engine`)**：推力倍率 `1.85x`，**支持开启加力燃烧室（WEP，推力额外 ×1.42）**。开启加力时尾部喷出烈焰且红外热源信号剧增。
* **地面加油**：手持 `煤炭 / 木炭 / 煤炭块 / 烈焰棒 / 烈焰粉 / 熔岩桶` 对准飞机**右键**即可补充燃油（用熔岩桶加油会返还空铁桶）。
* **回收飞机**：按住 **潜行（Shift）+ 空手右键** 停稳的飞机即可将其收回为物品（保留机内剩余油量与发动机类型）。

## 二、 微软模拟飞行级：冷舱启动流程（Cold & Dark Startup Checklist）

新放置或刚坐进驾驶舱的飞机处于**冷舱断电（Cold & Dark）**状态。直接推油门不会产生任何推力，主画面右上角会实时显示冷舱检查单，未完成项以黄色 `[ ]` 高亮提示。

### 标准启动五步流程：
1. **`[B]` 开启主电瓶 (Master Battery ON)**
   * 接通全机 28V 直流母线电源。
   * **联动效果**：主画面平显（HUD）通电点亮，同时允许开启机载火控雷达（若电瓶关闭，机载雷达会自动断电）。
2. **`[F]` 开启电动燃油泵 (Fuel Pump ON)**
   * 建立发动机供油管路油压（需确保飞机油量 `FUEL > 0%`）。
3. **`[G]` 切换磁电机/点火电门至 `BOTH` (Magnetos OFF → L → R → BOTH)**
   * 每按一次 `[G]` 依次切换：`OFF`（断电）→ `L`（左磁电机）→ `R`（右磁电机）→ `BOTH`（双磁电机工作）。
   * *注：仅单侧磁电机（L 或 R）工作时发动机最高推力会损失约 8%；切回 `OFF` 会立即切断点火使发动机停车。*
4. **`[按住 I]` 启动机点火 (Hold Starter to Crank RPM)**
   * 在满足 **主电瓶 ON + 燃油泵 ON + 磁电机非 OFF + 有燃油** 的前提下，**持续按住 `[I]` 键约 1.5 秒**。
   * 启动马达会带动发动机转速（RPM）从 `0%` 攀升，当转速越过 **`22%` 点火阈值**时气缸/燃烧室成功点火，发动机进入怠速运转（约 `24% RPM`）。
5. **`[P]` 解除驻车刹车 (Parking Brake OFF)**
   * 按 `[P]` 释放机轮驻车刹车，按 `[V]` 放下起飞襟翼至 `15° (TO)`，随后按住 `[R]` 柔和推油门滑跑起飞！

## 三、 飞机驾驶与气动控制快捷键总表

> **注意**：为避免与战雷式雷达的 `Alt + 键位` 冲突，所有纯飞机操控键均要求**不按住 `Alt`** 时触发；按住 `Alt` 时则触发原有的雷达/导弹快捷键。

| 按键 | 功能名称 | 详细说明与气动效果 |
| :---: | :--- | :--- |
| **`B`** *(不按 Alt)* | **主电瓶开关 (Master Battery)** | 控制全机航电、主画面飞行 HUD 及机载火控雷达供电 |
| **`F`** *(不按 Alt)* | **电动燃油泵开关 (Fuel Pump)** | 控制主油箱增压供油；飞行中关闭会导致发动机断油熄火 |
| **`G`** | **磁电机电门 (Magnetos)** | 循环切换 `OFF / L / R / BOTH`；切回 `OFF` 可紧急关停发动机 |
| **`按住 I`** *(未点火时)* | **发动机启动马达 (Starter)** | 冷舱启动时按住带动曲轴/涡轮旋转，RPM > 22% 自动完成点火 |
| **`P`** | **驻车刹车 (Parking Brake)** | 地面停机防溜车锁死；起飞滑跑前必须按 `P` 解除 |
| **`R`** 或 **`PageUp`** | **增加油门 / 开启加力 (Throttle Up)** | 持续推大节流阀（0% → 100%）；若安装**涡轮喷气发动机**，继续推至 `>100%` 将点燃 **WEP 加力燃烧室 (最高 110%)** |
| **`Y`** 或 **`PageDown`** | **减小油门 (Throttle Down)** | 持续收小节流阀，退出加力或降至慢车/零推力 |
| **`W` / `S`** *(不按 Alt)* | **升降舵俯仰 (Pitch Down / Up)** | **`S` 拉杆抬头（Pitch Up）**，**`W` 推杆低头（Pitch Down）**；控制迎角（AoA）与法向过载（G） |
| **`A` / `D`** *(不按 Alt)* | **副翼横滚 (Roll Left / Right)** | 控制飞机左右坡度（Bank Angle）；横滚坡度会产生协调转弯向心力 |
| **`Z` / `N`** | **方向舵偏航 (Yaw Left / Right)** | 地面滑行时控制前轮转向；空中飞行时修正侧滑角与横滚协调 |
| **`V` / `U`** | **放下 (`V`) / 收起 (`U`) 襟翼 (Flaps)** | 三档切换：`0° (UP)` ↔ `15° (TO 起飞档)` ↔ `40° (LDG 着陆档)`。放襟翼可显著降低失速速度，但会增大气动阻力；**高速超速不收襟翼会导致襟翼卡死警告** |
| **`K`** | **收放起落架 (Landing Gear)** | 起飞离地后按 `K` 收起起落架以消除寄生阻力；着陆前必须放下，否则机腹擦地会产生剧烈摩擦与机身损伤；**高速状态强行不收起落架会导致起落架受损** |
| **`]` / `[`** | **升降舵配平 (Elevator Trim)** | `]` 抬头配平，`[` 低头配平（步进 `0.5°`，范围 `-10° ~ +10°`），用于长途巡航免持平飞 |
| **`Space (空格)`** | **机轮点刹 (Wheel Brake)** | 地面滑跑降落时按住空格进行机轮减速刹车 |
| **`Left Shift (左 Shift)`** | **离开座舱 / 跳伞** | 下飞机 |

### 核心拟真气动特性：
* **真实升力与迎角（AoA）**：飞机并非“指哪飞哪”，机头姿态角（Pitch）与实际速度矢量（FPV 飞行轨迹标）之间存在真实的**迎角（$\alpha$）**。必须达到起飞抬轮速度（约 `12~16 b/s`）并拉杆建立迎角才能产生足够升力离地。
* **临界失速与尾旋改出（Stall Physics）**：当迎角超过临界值（`AoA > 15.5°`）或空速低于失速速度时，主画面中央闪烁红色 **`STALL / 失速警告`**，升力骤降、机头自动下坠并伴随翼尖失速抖振。**改出方法**：推杆低头（`W`）减小迎角并推满油门（`R`）恢复空速。
* **过载与黑视/红视（G-Load & G-LOC）**：高速急拉杆会产生高正过载（最高可达 `+9G`）。当持续超过 `+7.5G` 时飞行员会出现**黑视（Blackout）**视野遮蔽；负过载低于 `-3.0G` 时会出现**红视（Redout）**，超过机体极限过载会造成机体结构损伤。

## 四、 机载雷达、RWR、超视距（BVR）与导弹火控快捷键总表

飞机与 MineThunder 现有的雷达、TWS、BVR、RWR 及红外/雷达制导导弹系统**深度原生联动**：
* **雷达与 BVR 目标特征**：升空的飞机作为标准空中目标（`AIR`）可被 `SRC PD / TWS / ACM / STT` 及 `1000 b` 超视距 BVR 数据链探测跟踪；地面滑行速度 `≥ 2.0 b/s` 的飞机可在对地动目标模式（`GMI`）下被截获。本机雷达与导引头自动剔除自身座驾。
* **动态发动机红外热源（IR Heat）**：
  * 冷舱停车（Engine OFF）：红外热值 `0`（红外弹无法锁定）。
  * 熔炉/液冷/喷气常规推力：红外热值随油门在 `70 ~ 260` 间动态变化。
  * **喷气机开启加力（WEP）**：红外热值飙升至 **`480`**（甚至高于热焰弹的 `280`！）。**被红外弹锁定时，必须先按 `Y` 收油门关闭加力，再按 `Alt + E` 抛射热焰弹才能成功诱偏导弹！**
* **机载挂架发射与载机初速继承**：在驾驶舱内发射导弹时，导弹从机腹下前方挂架生成（永不误碰自身飞机碰撞箱），并 **100% 继承飞机当前的三维空速矢量**（高速巡航发射可显著提升导弹射程与不可逃逸区 NEZ）。

### 雷达与武器快捷键一览：
| 按键 | 功能名称 | 说明 |
| :---: | :--- | :--- |
| **`Alt + R`** | **机载雷达总开关** | 开启/关闭左下角雷达面板（需飞机主电瓶 `B` 处于开启状态） |
| **`Alt + B`** | **切换雷达工作模式** | 循环切换 `SRC PD`（脉冲多普勒搜索）→ `TWS`（边扫描边跟踪）→ `GMI`（地面动目标）→ `SEA`（海面搜索） |
| **`Alt + W`** | **ACM 近距格斗模式** | 一键进入/退出机头视轴内自动截获模式 |
| **`Alt + Q`** | **切换雷达量程档位** | 搜索模式：`20 / 50 / 100 / 200 / 500 / 1000 b`；ACM 模式：`50 / 100 / 150 b` |
| **`Alt + D`** | **切换扫描宽度 / ACM 波束** | 搜索模式切换方位角×行数；ACM 模式切换 `正前静止 / 上下往复 / 3×3 光栅` |

| **`Alt + F`** | **雷达锁定 / 解除锁定** | 对选中目标发起 `ACQ PD` 截获并转入 `TRK PD (STT)` 连续单目标跟踪 |

| **`Alt + X`** | **导弹导引头开关** | 开启/关闭当前选中弹种（ARH / SARH / IR）的导引头环 |
| **`C`** | **切换导弹制导类型** | 循环切换 `ARH`（主动雷达弹）→ `SARH`（半主动雷达弹）→ `IR`（红外格斗弹） |

## 五、 调试与靶机测试指令

在开启作弊的存档中，可使用以下指令快速测试飞机、雷达与导弹：
* `/minethunder test kit`：一键领取测试装备包
* `/minethunder test plane`：在正前方 80 格生成一架开启雷达热源、巡航飞行的喷气靶机（`BOGEY-JET`）
* `/minethunder test plane afterburner`：在正前方生成一架**开启加力燃烧室（WEP）**的高热源喷气靶机（`BOGEY-JET-AB`）
* `/minethunder test plane clear`：清除所有无人靶机
* `/minethunder test bvr`：在远距离生成带区块保活的超视距 BVR 测试目标
* `/minethunder test incoming <arh|sarh|ir>`：生成一枚朝玩家或座机袭来的测试导弹以测试 RWR 告警、收油门与干扰弹规避
* `/minethunder sensor`：开启/关闭 3D 传感器波束与热源可视化调试视图
